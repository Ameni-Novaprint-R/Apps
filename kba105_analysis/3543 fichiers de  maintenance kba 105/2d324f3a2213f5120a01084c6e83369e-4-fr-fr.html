3.

Appuyez sur le menu déroulant.

▷

Une liste de tous les supports d’impression enregistrés apparaît.

4.

Sélectionnez un support d’impression. Appuyez pour ce faire sur le nom du support d’impression souhaité.

Le support d’impression choisi doit correspondre à la qualité de surface et éventuellement à la coloration du support. Il n’est pas absolument nécessaire de créer un support d’impression particulier pour chaque sorte de support.

Si le support d’impression employé n’est pas dans la liste, vous pouvez le créer avec l’éditeur de supports d’impression (voir Chap. «Création de nouveaux supports d’impression»).

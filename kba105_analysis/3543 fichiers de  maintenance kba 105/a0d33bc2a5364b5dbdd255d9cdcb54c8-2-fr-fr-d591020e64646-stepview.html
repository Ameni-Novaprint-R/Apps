Verrouillage de la marge après détection de double feuille

a0d33bc2a5364b5dbdd255d9cdcb54c8-2-fr-fr.html

1.

Si une double feuille se trouve sur la table de marge :

Enlevez la feuille de tirage de la table de marge.

▷

La marge est libérée.

▷

Le message d’erreur disparaît.

2.

Si aucune double feuille ne se trouve sur la table de marge :

Vérifiez le réglage de la tête de marge sur le margeur.

3.

Vérifiez le réglage de la table de marge.

4.

Vérifiez le réglage de la marge.

5.

Vérifiez que les capteurs sont propres.

6.

Si les capteurs sont souillés :

Nettoyez les capteurs régulièrement. Sinon, les contrôles de marge fonctionnent de façon erronée et le processus de production est perturbé.

7.

Vérifiez que le contrôle de double feuille et le support d’impression sont compatibles (voir Chap. «Vue d’ensemble du contrôle de double feuille»).

8.

Équilibrez le contrôle de double feuille.

9.

Si nécessaire :

Ouvrez le menu de l’écran tactile Liste des messages (voir Chap. «Liste des messages de la marge»).

10.

Validez le message d’erreur.

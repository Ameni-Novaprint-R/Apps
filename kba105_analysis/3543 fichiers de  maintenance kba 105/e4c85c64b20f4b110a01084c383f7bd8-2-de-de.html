Anlaufwarnung

Die Anlaufwarnung ist ein vom Steuerprogramm der Maschine automatisch ausgelöstes Hupsignal vor dem Anfahren der Maschine. Wenn Sie per Tastenbetätigung ein Laufkommando geben, dann ertönt die Anlaufwarnung. Ab dann läuft eine Freigabezeit. Innerhalb dieser Freigabezeit muss die Taste für das Laufkommando ein zweites Mal betätigt werden.

Beispiele für Laufkommandos:

●

Maschinenlauf starten

●

Fortdruck starten

●

Tippen vorwärts

●

Tippen rückwärts

●

Schleichgang vorwärts

●

Schleichgang rückwärts

●

Druckplatte ausspannen

●

Druckplatte einspannen

Stellen Sie vor Betätigung der Bedienelemente sicher, dass durch Einleiten oder Anhalten einer Bewegung keine Person gefährdet oder verletzt wird. Bauteile der Maschine dürfen dadurch nicht beschädigt werden.

Eine Taste für ein Laufkommando wird betätigt. Anschließend wird die Taste losgelassen. Es ertönt eine Anlaufwarnung für eine Zeit von 3 s. Anschließend müssen Sie die Taste innerhalb der darauffolgenden Bereitschaftszeit von 6 s ein zweites Mal betätigen. Das Laufkommando wird ausgelöst. Wenn die Bereitschaftszeit überschritten wird, muss das Procedere wiederholt werden.

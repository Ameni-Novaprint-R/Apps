Pos.

Bezeichnung

1

Bogenniederhalter mit Rollen

2

Sensor für kapazitive Doppelbogenkontrolle

3

Sensor für Ultraschall-Doppelbogenkontrolle

1.

Legen Sie einen Auflagebogen auf dem Anlegtisch an die Vordermarken an.

2.

Betätigen Sie die Taste kapazitive Doppelbogenkontrolle.

▷

Die Doppelbogenkontrolle wird auf den Bedruckstoff abgeglichen.

▷

Die Taste leuchtet.

3.

Wenn der Auflagebogen verspannt:

Schieben Sie die Bogenniederhalter in Richtung Maschinenmitte, damit der Auflagebogen nicht an die Sensoren schlägt.

4.

Nehmen Sie den Auflagebogen vom Anlegtisch.

5.

Kontrollieren Sie die Sensoren der Doppelbogenkontrolle auf dem Anlegtisch auf Sauberkeit.

6.

Wenn Sensoren verschmutzt:

Reinigen Sie die Sensoren regelmäßig. Andernfalls funktionieren die Anlagekontrolle fehlerhaft und der Produktionsablauf wird gestört.

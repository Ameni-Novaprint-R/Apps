Saugstationen positionieren

Die Einstellungen erfolgen am Leitstand.

Voraussetzungen:

✓

Die Maschine steht still.

✓

Die Leitstandsmaske Saugstationen ist geöffnet siehe Kap. „Untermaske „Saugstationen““.

Einzelschritte

Für Saugstation 3 ist keine Parkposition wählbar.

1.

Wenn Saugstation in Parkposition fahren soll:

Wählen Sie die gewünschten Parkpositionen.

▷

Im Kontrollfeld ist ein Haken sichtbar.

Wenn Sie die Parkposition aktivieren, dann können Sie nicht die Position der Saugstation einstellen.

2.

Geben Sie die gewünschte Position der Saugstation ein.

3.

Betätigen Sie die Schaltfläche Einstellung aktivieren.

▶

Die Leitbügel (wenn vorhanden) fahren im Betrieb automatisch auf dieselbe Position wie die zugeordnete Saugstation.

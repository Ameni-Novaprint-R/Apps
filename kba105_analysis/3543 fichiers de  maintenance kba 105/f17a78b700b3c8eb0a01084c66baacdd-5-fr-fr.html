Réglages pour les conditions de mesure

1.

Appelez l’écran Mesure sur le poste de commande.

2.

Appuyez sur le bouton Réglages.

3.

Si l’option ErgoTronic ICR est disponible, la mesure de registre peut ici être activée ou désactivée : appuyez sur le bouton Mesure de registre.

▷

Lorsque la mesure de registre est activée, les marques de repérage dans la bande de contrôle d’impression sont mesurées en même temps pendant un trajet de mesure.

4.

La mesure L*a*b* peut ici être activée et désactivée : appuyez sur le bouton Mesure LAB.

5.

Activer ou désactiver le calibrage de slope : Appuyez sur le bouton Calibrage de slope.

▷

Avec le calibrage de slope, différents appareils de mesure sont rapportés à une référence commune. Cela se réfère à la mesure de densité. Lorsque le calibrage de slope est actif, l’arrière-plan de la ligne de menu avec les éléments de commande devient orange. De cette manière, le fait que la fonction est activée est visible.

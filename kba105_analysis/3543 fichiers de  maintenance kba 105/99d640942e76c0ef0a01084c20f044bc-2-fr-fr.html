Dans l’écran du poste de commande Carte de pile, vous configurez une carte de pile imprimable.

●

Il n’y a pas besoin pour l’utilisateur de la machine de remplir manuellement une carte de pile.

●

À partir de la commande de la presse, une carte de pile contenant des informations concernant la commande est imprimée d’après les paramètres de l’utilisateur de la machine. Pour ce faire, une imprimante doit être attribuée sur le poste de commande.

●

Une description détaillée de ce logiciel se trouve dans la documentation correspondante du fournisseur.

Pour pouvoir utiliser cette fonction, une imprimante correspondante doit être attribuée sur le poste de commande.

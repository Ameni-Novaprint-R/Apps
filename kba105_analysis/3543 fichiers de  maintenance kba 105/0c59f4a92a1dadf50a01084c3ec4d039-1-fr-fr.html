Redémarrage du mode d’urgence après un arrêt

La machine s’arrête après l’apparition d’un défaut dans la commande électrique. Lorsque la tour de vernissage est en service (circulation de vernis et alimentation en vernis), la tour de vernissage se met en mode d’urgence.

Pendant le mode d’urgence :

●

Le rouleau tramé continue à tourner.

●

Le vernis continue à circuler.

●

Le programme en cours s’interrompt.

●

Le clavier du poste de commande ne réagit plus.

●

Un message d’erreur apparaît au poste de commande.

Endommagement de la machine dû à du vernis séché !

▷Quand le mode d’urgence est arrêté, le vernis sèche très vite sur les pièces du groupe de vernissage.

▷Le rouleau tramé ne tourne pas et le vernis ne circule pas.

▬

Lancer rapidement le mode d’urgence.

Faire éliminer la panne uniquement par un personnel qualifié.

Le mode d’urgence est stoppé.

Le mode d’urgence est stoppé.

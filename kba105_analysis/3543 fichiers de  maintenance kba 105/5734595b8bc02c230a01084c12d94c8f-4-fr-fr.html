Une fois la tâche chargée, les réglages s’effectuent dans l’écran du poste de commande Support d’impression.

Conditions préalables :

✓

La machine est activée.

✓

La machine est à l’arrêt.

✓

La tâche est chargée.

✓

L’écran du poste de commande Support d’impression est ouvert (voir Chap. «Sous-écran «Support d’impression»»).

Étapes

1.

Sélectionnez un support d’impression dans la liste.

▷

Le support d’impression a un fond coloré.

2.

Appuyez sur le bouton Afficher les détails.

▷

La vue détaillée s’ouvre.

  • Accueil
  • Poste de commande
  • Exploitation
  • Configuration et réglage de la machine
  • Écran principal «Commande»
  • Configuration du support d’impression
  • Modification du support d’impression

Menu principal du margeur

Le fonctionnement de la machine peut être surveillé dans le Menu principal de l’écran tactile.

Vous pouvez appeler le menu principal à l’aide du bouton Menu principal.

Si aucun bouton n’est actionné sur l’écran tactile pendant 30 secondes, le Menu principal du margeur s’ouvre automatiquement.

  • Margeur
  • Description de la machine
  • Éléments de commande

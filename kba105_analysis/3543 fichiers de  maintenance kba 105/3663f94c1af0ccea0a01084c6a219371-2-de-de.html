Sollwertübernahme aus ErgoTronic ColorControl/ColorDrive

So gelangen Sie von der Hauptebene des Programms zur entsprechenden Unterebene:

1.

Betätigen Sie die Schaltfläche Auswertung.

2.

Betätigen Sie die Schaltfläche Einstellungen.

3.

Betätigen Sie die Schaltfläche Farbwerkbezogene Einstellungen.

  • Start
  • Leitstand
  • Betrieb
  • Maschine einrichten und einstellen
  • Auftrag einrichten
  • Auftrag mit ErgoTronic ColorControl/ColorDrive einrichten
  • Sollwertübernahme aus ErgoTronic ColorControl/ColorDrive

Abb.: Leitstandsmaske Sollwertübernahme mit ErgoTronic ColorControl/ColorDrive

×

Abb.: Leitstandsmaske Sollwertübernahme mit ErgoTronic ColorControl/ColorDrive

4.

Quelle für die Farbdichte-Sollwerte festlegen: Drücken Sie auf die Umschaltfläche mit dem Dichtesymbol.

5.

Farbwerke für die Sollwertübernahme auswählen: Drücken Sie auf die entsprechenden Kontrollkästchen unter der Farbwerksdarstellung.

▷

Die Kontrollkästchen werden mit einem Häkchen markiert.

6.

Drücken Sie auf die Schaltfläche mit dem Häkchen rechts.

▷

Die aktuellen Farbdichte-Werte der markierten Farbwerke werden als neue Sollwertvorgaben an den Leitstand übermittelt.

▷

Die aktuellen Farbdichtewerte werden als neue Sollwertvorgabe an den Leitstand übermittelt. In der Folge wird die Regelung nach diesen neuen Dichtesollwerten durchgeführt. Bei Anbindung einer QualiTronic ColorControl übernimmt diese ebenfalls die neuen Solldichten.

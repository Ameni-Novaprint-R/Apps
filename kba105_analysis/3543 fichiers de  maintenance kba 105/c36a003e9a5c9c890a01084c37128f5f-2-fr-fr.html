Vue «Prise de contact par chat»

La vue Prise de contact par chat vous met en contact avec un technicien de service de Koenig & Bauer Sheetfed AG & Co. KG via une fenêtre de chat.

La fonction de chat ne constitue pas la norme. En règle générale, le technicien vous contacte par téléphone.

La prise de contact par chat peut être utilisée lorsque le contact par courriel n’a pas été sélectionné dans la Demande de service.

Pour commencer un écran d’attente s’ouvre.

  • Accueil
  • Poste de commande
  • Description de la machine
  • Écrans du poste de commande
  • Écran principal «Messages»
  • Sous-écran «Service de télémaintenance»
  • Koenig & Bauer PressCall (option)
  • Vue «Prise de contact par chat»

Dès que le technicien de service traite votre demande, la fenêtre de chat s’ouvre.

Le nom et une photo du technicien qui traite votre demande s’affichent.

L’historique de vos échanges avec le technicien est visible dans la fenêtre de chat.

Un minuteur tourne pendant le chat. Ce minuteur indique le temps restant avant l’arrêt automatique de la connexion VPN.

Le bouton Fermer la demande permet de terminer le chat et par conséquent le traitement de votre demande.

Vos messages destinés au technicien doivent être saisis dans le champ de saisie pour le chat.

Le bouton Envoyer le message vous permet d’envoyer le message préalablement saisi. Ce dernier apparaît dans la fenêtre de chat.

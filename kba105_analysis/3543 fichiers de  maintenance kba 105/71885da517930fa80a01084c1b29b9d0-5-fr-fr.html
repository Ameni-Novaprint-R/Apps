L’action a lieu sur le poste de commande.

Conditions préalables :

✓

La machine est à l’arrêt.

✓

La presse est vide.

✓

Tous les programmes sont terminés.

✓

L’écran du poste de commande Presse arrêt est ouvert (voir Chap. «Sous-écran «Arrêt machine»»).

▬

Appuyez sur le bouton Presse arrêt.

▷

Toutes les données sont enregistrées.

▷

Le programme du poste de commande est terminé.

▷

Le dispositif de mesure Koenig & Bauer est désactivé.

▷

L’interrupteur principal est automatiquement désactivé.

Une fois la presse arrêtée sur le poste de commande, vous pouvez désactiver les agrégats.

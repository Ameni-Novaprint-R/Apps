Dans le menu déroulant Enregistrer la sauvegarde dans le lecteur, sélectionnez le lecteur dans lequel vous souhaitez enregistrer la sauvegarde de données.

L’affichage Dernière date d’enregistrement vous indique à quelle date une sauvegarde des données a été enregistrée.

Les affichages concernant l’espace mémoire vous indiquent, après actionnement du bouton Espace mémoire nécessaire, l’espace mémoire que nécessite la sauvegarde de données ainsi que l’espace mémoire disponible sur le lecteur.

Le bouton Démarrage permet de lancer l’enregistrement de la sauvegarde de données.

Fenêtre contextuelle «Nouveau support d’impression»

Dans la fenêtre contextuelle Nouveau support d’impression, vous définissez un nouveau support d’impression. Celui-ci est ajouté à la liste des supports d’impression.

  • Accueil
  • Poste de commande
  • Description de la machine
  • Écrans du poste de commande
  • Écran principal «Commande»
  • Sous-écran «Support d’impression»
  • Fenêtre contextuelle «Nouveau support d’impression»

Pour ajouter un nouveau support d’impression, vous devez indiquer les données suivantes :

Symbole

Indications

Fonction

 NuméroLe numéro est automatiquement attribué au support d’impression.
 NomDans le champ de saisie, saisir un nom pour le support d’impression.
 Largeur du formatDans le champ de saisie, saisir la largeur du format du support d’impression.
 Longueur du formatDans le champ de saisie, saisir la longueur du format du support d’impression.
 ÉpaisseurSaisir l’épaisseur du support d’impression dans le champ de saisie.
 GrammageSaisir le grammage du support d’impression dans le champ de saisie.
Sens traversSélectionner le sens de marche «Sens travers» en cochant la case.
Sens machineSélectionner le sens de marche «Sens machine» en cochant la case.
Impression rectoSélectionner le mode de fonctionnement «Impression recto» en cochant la case.
 CommentaireEspace pour remarques supplémentaires concernant le support d’impression.

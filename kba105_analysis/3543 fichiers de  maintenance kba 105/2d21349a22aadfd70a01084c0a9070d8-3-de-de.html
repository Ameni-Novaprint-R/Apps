Dynamische Farbzonensteuerung aktivieren

Es wird unterschieden zwischen:

●

einer statischen Farbzonensteuerung

●

einer dynamischen Farbzonensteuerung

Symbol

Beschreibung

Statische Farbzonensteuerung

Die Farbzonenöffnungen werden direkt auf den empfohlenen Öffnungswert gesetzt. Empfohlen, wenn mit wenig Farbe gearbeitet wird.

Dynamische Farbzonensteuerung

Je nach Unter- oder Überfärbung gibt es 2 Varianten:

●

Die Farbzonenöffnungen werden zunächst weit geöffnet. Danach werden sie wieder bis auf die notwendige Position geschlossen.

●

Die Farbzonenöffnungen werden zunächst geschlossen. Danach werden sie bis auf die notwendige Position weit geöffnet.

Ziel ist es, die notwendige Färbung schnell zu erreichen. Diese Variante wird am häufigsten gewählt.

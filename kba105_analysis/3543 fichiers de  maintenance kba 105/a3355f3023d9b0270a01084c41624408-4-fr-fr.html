L’écran du poste de commande Rouleaux propose les fonctions suivantes :

Affichage

Fonction

Lavage des rouleaux

●

Sélectionner les groupes d’impression en cochant les cases correspondantes.

●

Saisir le numéro du programme de lavage souhaité dans le champ de saisie. L’affichage des programmes vous indique le numéro.

●

L’affichage de l’état (voir Chap. «Affichage de l’état») indique l’état actuel du programme de lavage.

Lavage du rouleau d’encrier

Sélectionner le lavage du rouleau d’encrier avec le cylindre d’impression des groupes d’impression en cochant les cases correspondantes.

Mise en contact des rouleaux toucheurs d’encrage avec la plaque d’impression

Sélectionner le lavage de la plaque d’impression avec le groupe d’encrage des groupes d’impression en cochant les cases correspondantes.

L’affichage des programmes affiche les cycles de lavage des programmes.

Affichage

Fonction

Affichage du nombre de cycles Eau sur rouleaux

Nombre de cycles durant lesquels l’eau est projetée sur les rouleaux, avec racle désactivée.

Affichage du nombre de cycles de lavage Eau sur rouleaux

Nombre de cycles de lavage durant lesquels l’eau est projetée sur les rouleaux, avec racle activée.

Affichage du nombre de cycles Agents de nettoyage sur rouleaux

Nombre de cycles durant lesquels le produit de lavage est projeté sur les rouleaux, avec racle désactivée.

Affichage du nombre de cycles de lavage Agents de nettoyage sur rouleaux

Nombre de cycles de lavage durant lesquels le produit de lavage est projeté sur les rouleaux, avec racle activée.

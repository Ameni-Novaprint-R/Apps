Dosage d’additif

●

Selon la qualité de l’eau, l’ajout d’environ 1 … 2 % d’additif est nécessaire.

●

Pour effectuer le mélange, utiliser le bidon d’eau qui se trouve dans l’armoire à pompe.

●

Le bidon d’eau doit être entièrement vidé et rincé.

●

Utiliser de l’eau de lavage propre pour remplir le bidon d’eau. (attention à la qualité de l’eau)

●

Utiliser un verre mesureur pour mesurer la quantité nécessaire d’additif. (contenance 500 ml)

●

Après utilisation, le bidon d’eau doit être replacé dans l’armoire à pompe.

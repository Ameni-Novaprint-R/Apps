Abb.: Leitstandsmaske Datensicherung

Pos.

Bezeichnung

1

Dropdown-Menü Backup speichern in Laufwerk

2

Anzeige letztes Speicherdatum

3

Anzeigen zum Speicherplatz

4

Schaltfläche Speicherbedarf

5

Schaltfläche Start

Einzelschritte

1.

Wählen Sie das Laufwerk für die Datensicherung aus dem Dropdown-Menü aus.

▷

Das Dropdown-Menü wird geschlossen.

▷

Das ausgewählte Laufwerk wird im Auswahlfeld angezeigt.

2.

Betätigen Sie die Schaltfläche Speicherbedarf.

▷

Status: Interner Backup wird ausgeführt.

Erscheint die Fehlermeldung: „Freier Speicher auf Ziellaufwerk kann nicht ermittelt werden“?

Das ausgewählte Laufwerk ist nicht verbunden.

1.

Wählen Sie ein anderes Laufwerk zur Datensicherung aus.

2.

Betätigen Sie erneut die Taste Speicherbedarf.

3.

Wenn der Speicherbedarf und der freie Speicherplatz ermittelt sind:

Betätigen Sie die Schaltfläche Start.

▷

Nach kurzer Wartezeit wird eine Erfolgsmeldung angezeigt.

4.

Bestätigen Sie die Erfolgsmeldung mit der Schaltfläche OK.

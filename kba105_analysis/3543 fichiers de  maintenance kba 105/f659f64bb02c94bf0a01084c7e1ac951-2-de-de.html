Waschprogramm starten

Für die Abarbeitung der parallelen Waschvorgänge wählen Sie das Programm Gesamtwaschen vor. Die separate Abarbeitung von Waschvorgängen ist auch über die Teilprogrammvorwahl möglich.

Einzelschritte

1.

Drücken Sie die Schaltfläche Start / Stopp.

▷

Ein Hupton ertönt.

Den nächsten Schritt muss innerhalb von 6 Sekunden durchgeführt werden.

2.

Drücken Sie die Schaltfläche Start / Stopp.

▷

Die Taste blinkt.

▷

Die Maschine läuft in Grunddrehzahl.

Das Programm kann noch geändert werden.

3.

Drücken Sie die Schaltfläche Start / Stopp.

▷

Die Taste leuchtet.

▷

Das Programm wird gestartet.

▷

Der technologische Steuerungsablauf wird automatisch abgearbeitet.

Das Programm kann nicht geändert werden.

Die Maschine kehrt nach Programmende immer zur Grunddrehzahl zurück.

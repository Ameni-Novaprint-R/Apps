Volltondichten anzeigen

So gelangen Sie von der Hauptebene des Programms zur entsprechenden Unterebene.

1.

Betätigen Sie die Schaltfläche Auswertung.

2.

Betätigen Sie die Schaltfläche Messauswertung Online.

3.

Betätigen Sie die Schaltfläche Volltondichten. Die folgende Maske öffnet sich automatisch:

  • Start
  • Leitstand
  • Betrieb
  • Maschine einrichten und einstellen
  • Auftrag einrichten
  • Auftrag mit ErgoTronic ColorControl/ColorDrive einrichten
  • Volltondichten anzeigen

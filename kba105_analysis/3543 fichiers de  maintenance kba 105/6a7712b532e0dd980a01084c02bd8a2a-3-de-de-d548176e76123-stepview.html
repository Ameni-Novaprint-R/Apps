Abb.: Wechselspindel am Waschbalken

Pos.

Bezeichnung

1

Verriegelungsknopf auf der Antriebsseite

2

Schmutztuchspindel auf der Antriebsseite

3

Saubertuchspindel auf der Bedienseite

4

Verriegelungsknopf auf der Bedienseite

1.

Setzen Sie eine Saubertuchspindel mit sauberem Waschtuch in Lager auf Antriebsseite des Waschbalkens.

2.

Ziehen Sie den Verriegelungsknopf auf der Bedienseite nach außen.

3.

Schwenken Sie eine Saubertuchspindel ins Lager auf der Bedienseite ein.

4.

Rasten Sie den Verriegelungsknopf ein. Achten Sie dabei darauf, dass der Verriegelungsknopf richtig eingerastet ist.

5.

Führen Sie eine leere Schmutztuchspindel auf der Antriebsseite in die Aufnahme ein.

6.

Ziehen Sie den Verriegelungsknopf auf der Bedienseite heraus.

7.

Schwenken Sie die Schmutztuchspindel auf der Bedienseite ein.

8.

Lassen Sie den Verriegelungsknopf los.

9.

Drehen Sie den Verriegelungsknopf, bis dieser richtig eingerastet ist.

Abb.: Waschtuch am Waschbalken abziehen

Pos.

Bezeichnung

1

Saubertuchspindel

2

Waschtuch

3

Gummimembran

4

Rohrtraverse

5

Schmutztuchspindel

10.

Ziehen Sie das Waschtuch von der Saubertuchspindel.

11.

Ziehen Sie das Waschtuch über die Gummimembran und die Rohrtraverse.

12.

Wickeln Sie das Waschtuch fest auf die Schmutztuchspindel (2 bis 3 Lagen). Klemmen Sie das Waschtuchende in der Vertiefung auf der Schmutztuchspindel.

▷

Das Waschtuch ist über die gesamte Breite gleichmäßig straff (ohne Falten und Ausbauchungen) auf die Schmutztuchspindel aufgewickelt. Anderenfalls besteht die Gefahr, dass das Waschtuch mitgerissen und abgewickelt wird.

▷

Das Waschtuch sitzt fest auf der Schmutztuchspindel. Wenn sich die Schmutztuchspindel dreht, wird das Waschtuch transportiert. Eine leer drehende Schmutztuchspindel ohne transportiertes Waschtuch hat ein schlechtes Waschergebnis zur Folge.

 Das Waschtuch auf der Schmutztuchspindel hat Falten oder Ausbauchungen. Das Waschtuch ist nicht fest mit der Schmutztuchspindel verbunden.

Das Waschtuch auf der Schmutztuchspindel hat Falten oder Ausbauchungen. Das Waschtuch ist nicht fest mit der Schmutztuchspindel verbunden.

1.

Wickeln Sie das Waschtuch von der Schmutztuchspindel ab.

2.

Wickeln Sie das Waschtuch mit 2-3 Lagen fest auf die Schmutztuchspindel.

3.

Prüfen Sie erneut und wiederholen Sie die Arbeit bei Bedarf.

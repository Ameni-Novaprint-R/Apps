Farbzonenwerte spiegeln

89393875ae87dcf60a01084c14339a3a-3-de-de.html

1.

Wählen Sie ein Druckwerk in der Interaktiven Maschinenübersicht aus.

▷

Das Farbprofil des Druckwerks wird angezeigt.

2.

Setzen Sie einen Haken bei Farbzonenwerte spiegeln.

3.

Wenn alle gewünschten Druckwerke aktiviert sind:

Betätigen Sie die Schaltfläche Start.

▷

Die Farbzonenwerte werden gespiegelt.

4.

Wenn Einstellungen zurückgesetzt werden sollen:

Betätigen Sie die Schaltfläche Rückgängig.

▷

Die Einstellungen aller Druckwerke werden zurückgesetzt.

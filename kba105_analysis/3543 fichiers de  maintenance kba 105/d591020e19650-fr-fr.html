Dans la fenêtre contextuelle Base de données des couleurs groupe d’impression, vous pouvez sélectionner les fonctions suivantes :

Fonction

Rechercher

Dans le champ de saisie, saisir la couleur recherchée. Actionner le bouton pour lancer la recherche.

Annuler

Annuler l’opération et fermer la fenêtre contextuelle Base de données des couleurs groupe d’impression.

Accepter la couleur

Accepter l’encre sélectionnée pour le groupe d’encrage.

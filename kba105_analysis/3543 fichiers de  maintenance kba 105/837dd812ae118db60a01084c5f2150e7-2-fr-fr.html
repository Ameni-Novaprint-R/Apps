L’écran du poste de commande Ventilateur de groupe d’encrage vous permet d’effectuer des réglages sur le ventilateur de groupe d’encrage. Les ventilateurs du groupe d’encrage éliminent l’excès d’agent de mouillage qui se trouve dans le groupe d’encrage. Un excès de solution de mouillage peut apparaître dans le cas de couleurs métalliques ou de couleurs spéciales.

Chaque groupe d’encrage contient des ventilateurs placés sous la protection qui se trouve entre le côté commande et le côté entraînement. Ces ventilateurs peuvent être utilisés ensemble ou individuellement.

Fonctions de la vue

La vue d’ensemble interactive de la presse vous permet de sélectionner les groupes d’impression individuellement, en groupes ou dans l’ensemble.

Dans les fonctions, vous définissez l’intensité de l’air de soufflerie et de l’aspiration de nuages d’encre dans les groupes d’encrage en saisissant les valeurs correspondantes dans les champs de saisie.

En cochant les cases, vous sélectionnez les ventilateurs côté commande et côté entraînement dans les différents groupes d’encrage.

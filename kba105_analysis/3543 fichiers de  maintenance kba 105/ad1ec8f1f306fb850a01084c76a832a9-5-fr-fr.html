Suppression des supports d’impression

1.

Appelez l’écran Support d’impression sur le poste de commande.

×

Fig.: Écran du poste de commande Supports d’impression

2.

Appelez l’écran Éditeur de support d’impression sur le poste de commande.

3.

Dans la ligne de chaque support d’impression souhaité, appuyez sur le bouton Supprimer le support d’impression.

▷

Le support d’impression correspondant est sélectionné en vue de son effacement.

▷

À la fin de la ligne, le bouton Supprimer le support d’impression devient Annuler l’effacement du support d’impression.

4.

Annuler la pré-sélection pour la suppression d’un support d’impression : appuyez sur le bouton Annuler l’effacement du support d’impression.

5.

Supprimer le support d’impression : appuyez sur le bouton Appliquer.

▷

Tous les supports d’impression pré-sélectionnés sont supprimés. Ces supports d’impression ne sont plus proposés dans le menu déroulant de sélection des supports d’impression.

6.

Annuler la sélection du support d’impression : appuyez sur le bouton Annuler.

▷

La présélection est annulée, les supports d’impression sont conservés.

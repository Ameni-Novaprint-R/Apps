In der Filterliste legen Sie durch Setzen von Haken fest, welche Daten des ausgewählten Auftrags beim Auftragswechsel übernommen werden.

Das Filtern geschieht auf mehreren Ebenen. Wenn Sie auf einer Ebene keinen Haken bei einer Funktion setzen, dann können Sie keine Änderungen auf allen nachfolgenden Ebenen der gleichen Funktion vornehmen.

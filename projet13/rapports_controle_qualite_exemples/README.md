# Rapports de contrôle qualité – fichiers exemples

Ce dossier est destiné à recevoir des **exemples de rapports PDF** générés par la machine de contrôle qualité.

## Instructions

1. **Déposez ici** un ou plusieurs fichiers PDF d’exemple issus de votre machine de contrôle qualité.
2. Le format et la structure de ces fichiers seront analysés pour adapter la future section « Analyse des rapports de contrôle qualité » du Projet 13.
3. Une fois les exemples analysés, la section permettra de :
   - télécharger des rapports PDF ;
   - analyser leur contenu ;
   - générer des graphiques pour faciliter la lecture des résultats.

## Contexte

La machine de contrôle qualité utilise des capteurs pour détecter les défauts des articles produits. Les produits défectueux sont automatiquement triés et écartés des produits conformes. Les rapports PDF produits par cette machine contiennent ces données de contrôle.

Tab.: Sélection du sujet de la demande de service

Les boutons de sélection du niveau de priorité vous permettent de sélectionner l’état actuel de la machine.

Bouton

Fonction

Priorité - Bleu

Ce bouton permet d’indiquer que la machine peut poursuivre la production.

La priorité de la demande est classée comme faible.

Priorité - Jaune

Ce bouton permet d’indiquer que la machine peut poursuivre la production de façon restreinte.

La priorité de la demande est classée comme moyenne.

Priorité - Rouge

Ce bouton permet d’indiquer que la machine ne peut pas produire.

La priorité de la demande est classée comme élevée.

Tab.: Priorité de la demande

Le champ de texte Description permet de décrire le problème rencontré. Il est impératif de remplir ce champ pour accéder à la vue suivante.

Vous pouvez demander à être contacté par Koenig & Bauer Sheetfed AG & Co. KG par courriel.

Le bouton Retour vous permet de supprimer vos données et de revenir à l’écran de démarrage.

Le bouton Suivant vous permet de valider vos données et d’ouvrir la vue Coordonnées. Le bouton ne peut être utilisé que si le champ Description a été complété.

Application et déroulement des programmes

Les fonctions Pré-encrage et Amenée d’encre se déroulent de manière identique. Elles peuvent chacune être activées pour un groupe d’encrage ou pour plusieurs. Une seule des deux fonctions peut être activée dans un groupe d’encrage.

Fonction

Application

Pré-encrage

quand un groupe d’encrage vide doit être rempli d’encre après un changement de travail

Amenée d’encre

quand, après utilisation de la fonction Pré-encrage, trop peu d’encre se trouve dans le groupe d’encrage ou quand vous avez besoin lors d’un changement de travail de davantage d’encre dans le groupe d’encrage

Exemple : dans la nouvelle commande, l’épaisseur de la couche de base reste la même que lors de la commande précédente, mais le profil d’encre de la nouvelle commande a changé. Par rapport à l’ancienne commande, la nouvelle commande a une couverture de surface clairement plus élevée si bien qu’un profil d’encre comportant plus d’encre s’avère nécessaire.

Le pré-encrage se déroule selon la même séquence consécutive avec les fonctions Pré-encrage et Amenée d’encre :

Phase

Description

Création d’une épaisseur de couche de base dans le groupe d’encrage

Une couche d’encre servant à la saturation de base des rouleaux est créée sur les rouleaux : il s’agit de la couche de base. La base permettant une séparation d’encre optimale lors du lancement du passage en pression est ainsi créée. Le profil des zones d’encrage sur les rouleaux est pour la plupart uniforme. Il est légèrement plus élevé sur les bords des rouleaux.

●

Vitesse du rouleau d’encrier : automatiquement réglé par la commande de la presse

●

Cycles de preneur d’encre : nombre supérieur, en fonction de la saisie dans l’écran du poste de commande

Création d’un profil de travail dans le groupe d’encrage

Le profil d’encre de la commande est réglé sur les rouleaux du groupe d’encrage. Les zones d’encrage s’ouvrent. Le profil d’encre entre en vigueur.

●

Vitesse du rouleau d’encrier : automatiquement réglé par la commande de la presse

●

Cycles de preneur d’encre : nombre bas, en fonction de la saisie dans l’écran du poste de commande

 

Fin du pré-encrage :

●

Le preneur d’encre est bloqué.

●

La séparation de train d’encre est activée.

●

Le rouleau d’encrier tourne à la vitesse de base.

●

La présélection Passage en pression est possible.

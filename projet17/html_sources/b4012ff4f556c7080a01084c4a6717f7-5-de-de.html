Formateinstellungen

Im Touchpanel-Menü Formateinstellungen können Sie die Funktionen der Formateinstellungen anpassen.

Sie können das Touchpanel-Menü mit der Schaltfläche Formateinstellungen aufrufen.

Wenn Sie die jeweilige Funktion aufrufen, dann wird Ihnen der aktive Einstellungsstand angezeigt.

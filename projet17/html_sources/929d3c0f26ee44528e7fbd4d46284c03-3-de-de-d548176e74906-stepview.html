Abb.: Register in Seitenrichtung

Pos.

Bezeichnung

1

Stellschraube an der Antriebsseite

2

Spannschraube

3

Stellschraube an der Bedienseite

1.

Lösen Sie die Stellschraube an der Antriebsseite.

2.

Legen Sie die Spannschraube (2) an.

3.

Korrigieren Sie das Register mit der Stellschraube an der Bedienseite.

4.

Kontrollieren Sie nach der Korrektur der Plattenspannschiene, dass die Stellschrauben keinen direkten Kontakt zur Kanalkante haben.

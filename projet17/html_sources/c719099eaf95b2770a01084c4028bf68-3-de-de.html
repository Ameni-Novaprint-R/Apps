  • Farbzonenwerte kopieren/tauschen
×

Die Einstellungen erfolgen ausschließlich am Leitstand.

Voraussetzungen:

✓

Die Leitstandsmaske kopieren/tauschen ist geöffnet (siehe Kap. „Untermaske „Kopieren/Tauschen““).

Einzelschritte

1.

Wählen Sie ein Druckwerk in der interaktiven Maschinenübersicht aus, dessen Werte kopiert werden sollen.

2.

Wählen Sie ein Druckwerk aus, das die kopierten Farbzonenwerte übernehmen soll.

▷

Die Kopierrichtung wird mit Linien angezeigt.

3.

Betätigen Sie die Schaltfläche Farbzonenwerte übernehmen.

▷

Die Farbzonenwerte werden übernommen.

4.

Wenn Einstellungen zurückgesetzt werden sollen:

Betätigen Sie die Schaltfläche Rückgängig.

▷

Die Einstellungen aller Druckwerke werden zurückgesetzt.

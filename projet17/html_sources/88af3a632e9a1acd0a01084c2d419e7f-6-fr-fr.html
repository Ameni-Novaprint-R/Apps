Une fois la tâche chargée, les réglages s’effectuent dans l’écran du poste de commande Support d’impression.

Conditions préalables :

✓

La machine est activée.

✓

La machine est à l’arrêt.

✓

La tâche est chargée.

✓

L’écran du poste de commande Support d’impression est ouvert (voir Chap. «Sous-écran «Support d’impression»»).

Étapes

1.

Appuyez sur le bouton Nouveau support d’impression.

▷

La fenêtre contextuelle Nouveau support d’impression s’ouvre (voir Chap. «Fenêtre contextuelle «Nouveau support d’impression»»).

2.

Saisissez les valeurs du nouveau support d’impression.

3.

Appuyez sur le bouton Appliquer.

▷

Les valeurs pour le support d’impression sont enregistrées.

▷

Les valeurs définies actuellement dans la machine pour le guidage de feuille sont associées au support d’impression.

▷

La fenêtre se ferme.

▷

Le support d’impression est ajouté à la liste.

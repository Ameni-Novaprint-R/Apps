Spannschrauben vor dem Ausspannen der Lackierplatte lösen

d548176e81544-de-de.html

1.

Betätigen Sie die Taste Lackierplatte ausspannen.

▷

Die Lackierplatte wird entspannt.

2.

Lösen Sie die Spannschrauben der Plattenspannschiene „Druckende“.

3.

Stellen Sie die Spannschrauben der Plattenspannschiene „Druckanfang“ auf „0“.

4.

Betätigen Sie die Taste Lackierplatte ausspannen.

▷

Die Lackierplatte wird gespannt.

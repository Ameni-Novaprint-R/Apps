L’affichage des données d’exploitation modules UV vous fournit les informations suivantes :

Affichage

Description

Position actuelle dans la presseAffichage codé concernant le raccord d’un module UV.

C’est-à-dire : «6» : raccord dans le sécheur intermédiaire, «8» : raccord dans le groupe de séchage, «11» : raccord dans la sortie ou dans le rallongement de réception

Identifiant UVType de rayonnement - équipement des radiateurs UV
Modifier les valeurs de comptage  
Heures de fonctionnement lampe en module UV

Indique les heures de fonctionnement des différentes lampes dans les modules UV.

Le nombre d’heures de fonctionnement est modifié lorsque vous remplacez une lampe. Sur la nouvelle lampe, placez les heures d’exploitation sur «0». Sur la lampe usagée, inscrivez le nombre d’heures d’exploitation qu’elle a enregistrées jusqu’ici.

Nombre d’allumages de la lampe dans le module UVIndique le nombre d’allumages de la lampe.

Le nombre d’allumages est modifié lorsque vous remplacez une lampe. Sur la nouvelle lampe, réglez le nombre d’allumages sur «0». Sur la lampe usagée, inscrivez le nombre d’allumages qu’elle a enregistrés jusqu’ici.

Proportion d’UV de la lampeIndique la proportion d’UV d’une lampe. Un capteur intégré au module mesure cette proportion par pas de 10 %.

Tab.: Affichage des données d’exploitation modules UV

Identifiant UV indique le type de rayonnement - équipement des radiateurs UV : en fonction des divers photo-initiateurs des encres et vernis employés, différents types de radiateurs équipés différemment sont utilisés. De cette manière, le spectre d’émissions des radiateurs est placé dans la plage spectrale désirée.

●

Hg - radiateurs standard à équipement au mercure

●

Ga - radiateurs à équipement au gallium (employés en cas de teneur élevée en blanc opaque)

●

Fe - radiateurs à équipement au fer (employés avec encres hautement réactives)

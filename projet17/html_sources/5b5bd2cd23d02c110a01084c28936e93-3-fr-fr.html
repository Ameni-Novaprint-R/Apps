Un travail est un produit d’impression formé par un nombre total fini de feuilles. Pour permettre une identification univoque, chaque travail peut être décrit sur plusieurs niveaux.

Affichage

Description

Client

Nom du client

Travail : numéro, nom

Désignation du travail comme terme générique pour l’ouvrage complet à réaliser

Travail partiel : numéro, nom

Désignation éventuelle pour travaux partiels avec plusieurs feuilles

Passage de l’impression : numéro, nom

Désignation pour le travail avec plusieurs passages d’impression

Outre les niveaux, une travail contient également les données suivantes concernant les nombres de feuilles :

Affichage

Fonction

Volume de tirageAffichage du nombre de feuilles à fournir aux services suivants.
contient un supplémentAffichage des feuilles supplémentaires prises en compte.
BrutAffichage de toutes les feuilles qui entrent dans la presse.
Bonnes feuillesAffichage des feuilles qui atteignent la réception.
GâcheAffichage de la différence entre Brut et Bonnes feuilles.
Quantité de livraisonDans le champ de saisie, saisir le nombre d’exemplaires identiques à livrer.
PosesDans le champ de saisie, saisir le nombre d’exemplaires d’un produit imprimé présents sur la feuille d’impression.
Supplément impressionDans le champ de saisie, saisir le nombre de feuilles d’impression qui sont nécessaires en plus du volume de tirage.
Supplément traitement ultérieurDans le champ de saisie, saisir le nombre de feuilles d’impression qui sont nécessaires en plus pour le traitement ultérieur.

Tab.: Nombre de feuilles d’une commande

Dans le cas de la configuration «LogoTronic», il est impossible d’effectuer certains réglages. Les valeurs doivent être réglées dans «LogoTronic».

Le bouton Terminer vous permet de terminer le travail. En présence de «LogoTronic», le travail est marqué comme terminé dans «LogoTronic».

Le bouton Enregistrer vous permet d’enregistrer les données que vous avez saisies.

Le bouton Traiter vous permet d’activer le traitement des données de travail. Le bouton passe à Appliquer. Appliquer vous permet de confirmer les modifications que vous avez effectuées.

Le bouton Annuler vous permet d’annuler vos modifications.

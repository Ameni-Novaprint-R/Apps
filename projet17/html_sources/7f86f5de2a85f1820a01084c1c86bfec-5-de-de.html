Datenübergabe an das Auftragswechselprogramm

In der Registerkarte Datenübergabe an das Auftragswechselprogramm richten Sie das Auftragswechselprogramm für einen Auftrag ein.

Diese Datenübergabe wird bei häufigem Wechsel des Bedruckstoffs empfohlen.

  • Start
  • Leitstand
  • Maschinenbeschreibung
  • Leitstandsmasken
  • Hauptmaske „Auftragswechsel“
  • Ansicht „Auftrag vorbereiten“

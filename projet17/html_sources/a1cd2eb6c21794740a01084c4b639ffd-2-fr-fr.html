La liste de supports d’impression indique les données de tous les supports d’impression sélectionnables.

Le bouton Afficher/masquer les détails vous permet d’ouvrir la vue détaillée. Elle vous montre les détails des différents supports d’impression.

Le bouton Sélectionner vous permet de confirmer la sélection d’un support d’impression.

Le bouton Fermer vous permet de retourner à la zone Passage des feuilles.

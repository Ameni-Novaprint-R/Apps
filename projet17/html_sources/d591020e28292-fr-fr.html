Structure de l’affichage de registre

La vue d’ensemble des registres présente les valeurs définies de tous les registres des groupes d’impression et de vernissage.

L’affichage de registre des différents groupes d’impression et de vernissage possède la structure de base suivante :

  • Accueil
  • Poste de commande
  • Description de la machine
  • Écrans du poste de commande
  • Écran principal «Registre»
  • Sous-écran «Registre» (sans système de mesure)
  • Structure du sous-écran Registre
  • Structure de l’affichage de registre

Fig.: Feuchtmittel-Kühlgerät

1.

Kontrollieren Sie den Feuchtmittelfilter. Wechseln Sie einen verschmutzten Feuchtmittelfilter.

2.

Kontrollieren Sie den Schwimmerschalter auf Verschmutzung. Reinigen Sie einen verschmutzten Schwimmerschalter.

3.

Kontrollieren Sie den Fußfilter auf Verschmutzung. Reinigen Sie einen verschmutzten Fußfilter.

4.

Kontrollieren Sie den Frischwasserfilter auf Verschmutzung. Reinigen Sie einen verschmutzten Frischwasserfilter.

5.

Kontrollieren Sie den pH-Wert der Messsonde. Reinigen Sie eine verschmutzte Messsonde und/ oder kalibrieren Sie falsch messende Messsonde.

6.

Kontrollieren Sie den Manometerdruck am Feuchtmittelaustritt. Stellen Sie den Manometerdruck auf den richtigen Wert ein.

7.

Reinigen Sie den Kondensator und die Kühllamellen.

8.

Kontrollieren Sie die Filtertasse. Spülen Sie eine verschmutzte Filtertasse aus.

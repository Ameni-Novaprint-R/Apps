La vue détaillée vous fournit des informations supplémentaires concernant ces données. Le bouton Afficher/masquer les détails vous permet d’afficher ou de masquer la vue détaillée. Dans la vue détaillée, vous pouvez traiter les données concernant le support d’impression.

Le bouton Charger un support d’impression vous permet de charger dans la presse les valeurs du support d’impression actuellement sélectionné. Il apparaît une fenêtre contextuelle dans laquelle vous pouvez confirmer le chargement du support d’impression ou annuler l’opération.

Le support d’impression chargé en dernier est indiqué en gras dans la liste.

Le bouton Enregistrer un support d’impression vous permet d’enregistrer le support d’impression chargé auparavant. Une fenêtre contextuelle apparaît dans laquelle vous pouvez confirmer l’enregistrement du support d’impression ou annuler l’opération. Les valeurs définies actuellement dans la machine pour le guidage de feuille sont associées au support d’impression.

Les valeurs ne sont pas harmonisées avec les valeurs affichées dans l’écran du poste de commande Passage des feuilles ! voir Chap. «Sous-écran «Passage des feuilles»»

L’actionnement du bouton Nouveau support d’impression vous permet d’ouvrir la fenêtre contextuelle Nouveau support d’impression (voir Chap. «Fenêtre contextuelle «Nouveau support d’impression»»).

Le bouton Supprimer un support d’impression vous permet de supprimer de la liste le support d’impression actuellement sélectionné.

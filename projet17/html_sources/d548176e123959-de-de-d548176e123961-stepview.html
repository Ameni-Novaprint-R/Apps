2.

3.

4.

Entriegeln Sie die Elektrostecker des IR-Wechselmoduls und ziehen Sie die Elektrostecker ab.

5.

Setzen Sie die Schutzkappen auf die Elektroanschlüsse.

6.

Betätigen Sie den Entriegelungsschalter am IR-Wechselmodul.

▷

Das IR-Wechselmodul ist entriegelt.

7.

Fassen Sie den Griffmulden auf der Außenseite des Wechselmoduls.

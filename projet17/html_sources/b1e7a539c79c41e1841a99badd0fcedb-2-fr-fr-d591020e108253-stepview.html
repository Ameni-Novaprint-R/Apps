N°

Désignation

1

Cylindre distributeur d’encre

Retirer l’encre :

1.

appliquez le solvant d’encre sur le cylindre distributeur d’encre.

2.

Refermez la protection du groupe d’encrage.

3.

Laissez tourner la machine en marche lente 1 min.

4.

Laissez tourner la machine avec le programme Fonctionnement machine à vitesse de base 3–5 min.

5.

Lavez le solvant d’encre avec le programme Lavage des rouleaux.

Élimination du tartre :

6.

appliquez le solvant pour tartre sur le cylindre distributeur d’encre.

7.

Refermez la protection du groupe d’encrage.

8.

Laissez tourner la machine en marche lente 1 min.

9.

Laissez tourner la machine avec le programme Fonctionnement machine à vitesse de base 3–5 min.

10.

Lavez le solvant pour tartre manuellement à l’eau chaude.

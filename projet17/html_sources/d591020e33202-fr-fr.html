Sélection des sous-écrans avec écran Analyse/Affichage de la valeur mesurée sélectionné

Cochez les cases correspondantes pour sélectionner les groupes d’impression pour le contrôle des zones d’encrage (2).

L’affichage d’état Évolution des valeurs mesurées (3) vous permet de voir d’un coup d’œil les changements significatifs dans le processus d’impression.

Le bouton Réglages (4) permet d’ouvrir les réglages de l’affichage de la valeur mesurée.

Les boutons de commutation entre les vues (5) permettent de basculer entre les vues de l’écran du poste de commande.

Les boutons de commutation entre les fonctions (6) permettent de basculer entre les fonctions de la vue.

Les fonctions pour le contrôle des zones d’encrage (7) permettent de régler les ouvertures des zones d’encrage dans les groupes d’impression sélectionnés.

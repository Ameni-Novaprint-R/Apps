Bogenanlegerstapel manuell ausrichten

Die Einstellung wird am Touchpanel der Bogenanlage durchgeführt. Alternativ kann die Ausrichtung an der Bedientafel des Bogenanlegers auf gleiche Weise über die entsprechenden Tasten vorgenommen werden.

Voraussetzungen:

✓

Der Anlegerstapel ist seitlich auf Mitte ausgerichtet.

✓

Das Touchpanel-Menü Formateinstellungen ist geöffnet (siehe Kap. „Formateinstellungen“).

Einzelschritte

1.

Wenn der Stapel in Richtung Bedienseite korrigiert werden soll:

Betätigen Sie die Schaltfläche Manuelle Seitenkantenregelung Bedienseite.

▬

Wenn der Stapel in Richtung Antriebsseite korrigiert werden soll:

Betätigen Sie die Schaltfläche Manuelle Seitenkantenregelung Antriebsseite.

2.

Betätigen Sie die Schaltfläche Automatische Seitenkantenregelung.

▷

Die automatische Seitenkantenregelung ist aktiv.

▶

Der Bogenanlegerstapel wird automatisch auf der eingestellten seitlichen Position des Anlagesensors gehalten.

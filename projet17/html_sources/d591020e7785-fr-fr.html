Explication des désignations de type

Exemple d’explication de désignation de type «KBA2013 MF 5C 5bx3mmh SW A IF»

Élément

Explication

KBA 2013

Génération de bandes de contrôle d’impression Koenig & Bauer Sheetfed AG & Co. KG année 2013

MF

Classe de presse

KF : petit format (RA75/RA76), MF : format moyen (RA105/106), GF : grand format (RA145/164)

5C

Nombre d’encres mesurables

5bx3mmh

Indication de la taille de bande de contrôle d’impression en mm largeur x hauteur

Recto-verso

Indication du côté d’impression :

SW : bande de contrôle d’impression pour l’impression recto en mode rectiligne ou l’impression verso en mode de retournement

S+ : bande de contrôle d’impression pour l’impression recto en mode de retournement (presses RV, secteur sans impression élargi)

S++ : bande de contrôle d’impression pour impression d’une seule face (S) ou recto en impression R/V (SW) - milieu extra large/secteur sans impression

SWDL : bande de transparence pour impression verso

S+DL : bande de transparence pour impression recto avec secteur sans impression large

A

Position sur la feuille essentielle pour la mesure de registre, A : début, M : milieu, E : fin

Tab.: Explication des désignations de type

Fonctions possibles «IF» :

●

IF : pour Instrument Flight (couleur pure, trame 40 %/50 %/80 %, discontinuité, demi-ton gris - bande de contrôle d’impression standard adaptée à Instrument Flight(option) ou PSO Match (option) et utilisable pour ErgoTronic ColorCheck)

●

VT : uniquement couleur pure

●

IFEU : standard (couleur pure, trame 40 %/50 %/80 %, discontinuité, demi-ton gris - bande de contrôle d’impression standard adaptée à Instrument Flight et PSO Match (option) et utilisable pour ErgoTronic ColorCheck)

●

IFUS : Pour Instrument Flight (couleur pure, trame 25 %/50 %/75 %, discontinuité, demi-ton gris - bande de contrôle d’impression standard adaptée à Instrument Flight et PSO Match (option), utilisable spécialement en Amérique pour ErgoTronic ColorCheck)

●

IFG7 : pour Instrument Flight (couleur pure, trame 25 %/50 %/75 %, discontinuité, demi-ton gris - bande de contrôle d’impression standard adaptée à Instrument Flight et PSO Match (option), beaucoup de champs également pour les couleurs spéciales et le nouveau positionnement des champs G7)

●

VTRD : couleur pure avec trame 40 %/80 % CMYK et champs de tramage CMYK

●

VTRD+ : couleur pure, trame 40 %/80 % CMYK, champs de tramage spécial CMYK optimisés pour largeur d’image d’impression 1.420 mm (équipement spécial)

●

ISO : pour standard ISO (couleur pure, champs de mesure CMYK)

●

CRACol : pour standard US (couleur pure, trame 25 %/50 %/75 %, discontinuité, demi-ton (GC) gris)

●

VTRa : couleur pure, trame 40 %/80 % sur toutes les plaques d’impression (également Spot)

●

FGRa : couleur pure, trame 40 %/80 % sur toutes les plaques d’impression (également Spot), discontinuité, demi-ton gris

●

ISOD : pour standard ISO (couleur pure, champs de mesure CMYK, champs de tramage)

●

ICR : uniquement milieu de la feuille et marques de registre, pas de champs de couleur

●

GCAsia : pour GRACol Asia (couleur pure, 25 %/50 %/75 % CMYK, discontinuité, demi-ton (GC) gris, champs de tramage CMYK

●

RAlu : pour impression sur blanc opaque (couleur pure, champs de blanc du papier)

●

GRD : pour standard ISO (couleur pure, CMYK, discontinuité, champs de tramage CMYK)

●

StUK : pour le marché de l’imprimerie britannique (couleur pure, trame 40 %/80 %, balances de gris, discontinuité)

●

Ra50 : (couleur pure, trame 50 %)

●

ISORa : pour standard ISO (couleur pure, CMYK, quelques champs de trame de plus pour couleurs supplémentaires, permet un contrôle et un compte rendu)

●

GPI : pour le marché de l’imprimerie nord-américain (couleur pure, trame 25 %/50 %/75 %, discontinuité, demi-ton gris)

●

bVTR : couleur pure, trame

●

bVT : couleur pure

●

bRa50 : couleur pure, trame 50 %

●

YYVT : bande de contrôle d’impression propre au client pour la mesure de couleur opaque

●

StUs : pour le marché de l’imprimerie nord-américain (couleur pure, trame 25 %/50 %, discontinuité, demi-ton gris)

●

VTQa : couleur pure, champs de tramage, trame dans toutes les couleurs/plaques d’impression

●

MC1 : une bande de contrôle d’impression propre au client pour l’impression sept couleurs (MultiColor)

●

IRIS : pour l’impression irisée (couleur pure)

●

DVT : couleur pure

●

MC2 : une bande de contrôle d’impression propre au client pour l’impression sept couleurs (MultiColor)

●

VTraD : couleur pure, trame, champs de tramage

●

PSOKalib : deuxième bande de contrôle d’impression avec tous les champs de mesure pour le contrôle et le calibrage de la presse ou de la pré-presse selon le standard de procédure d’impression offset (PSO)

●

VT40 : couleur pure, trame 40 %

●

VTR50m : couleur pure, trame 50 %, champs de blanc du papier

●

VTRa4 : couleur pure, trame 10 %/25 %/50 %/75 %

●

Fonctions rares :

●

PSO : standard de processus d’impression offset (couleur pure, trame 40 %/80 % CMYK, discontinuité)

●

PSOD : couleur pure, 40 %/80 % CMYK, discontinuité, champs de tramage CMYK

Affichages concernant l’espace mémoire

5

Bouton Démarrage

Étapes

1.

Sélectionnez le lecteur de sauvegarde des données dans le menu déroulant.

▷

Le menu déroulant est fermé.

▷

Le lecteur sélectionné s’affiche dans le champ de sélection.

2.

Actionnez le bouton Espace mémoire nécessaire.

▷

Statut : la sauvegarde interne est en cours d’exécution.

Le message d’erreur suivant s’affiche : «Impossible de déterminer l’espace libre sur le disque cible» ?

Le lecteur sélectionné n’est pas connecté.

1.

Sélectionnez un autre lecteur pour la sauvegarde des données.

2.

Appuyez de nouveau sur la touche Espace mémoire nécessaire.

3.

Une fois l’espace mémoire nécessaire et l’espace libre déterminés :

Appuyez sur le bouton Démarrage.

▷

Après un bref temps d’attente, un message de confirmation s’affiche.

4.

Confirmez le message avec le bouton OK.

La liste énumère le personnel enregistré sur le poste de commande.

Le bouton Trier la liste permet d’afficher le personnel par ordre croissant ou décroissant.

Le personnel choisit son nom dans la liste et s’inscrit à l’aide du bouton Inscription. Le bouton Désinscription permet de désinscrire le personnel du poste de commande.

Le bouton Pause permet d’entrer le début d’une pause de travail dans la liste. Rappuyer sur le bouton pour quitter la pause.

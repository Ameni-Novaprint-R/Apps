Sélection de tous les tuyaux de soufflerie

Étapes

1.

Actionnez le bouton Sélectionner/désélectionner tous les champs de saisie.

▷

Tous les champs de saisie sont marqués.

2.

Actionnez les différents champs de saisie pour les tuyaux de soufflerie dont vous n’avez pas besoin.

▷

Les tuyaux de soufflerie inutiles sont déconnectés.

3.

Saisissez les valeurs que vous souhaitez dans les champ de saisie Réglage des valeurs.

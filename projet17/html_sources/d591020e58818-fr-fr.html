Commutation de l’air (chambres) pour support d’impression

Le bouton Commutation de l’air (chambres) pour support d’impression permet de sélectionner le réglage de l’air pour le support d’impression utilisé.

Les réglages de la fonction dont le symbole apparaît sur le bouton sont actifs.

Bouton

Fonction

Réglage de l’air pour carton

Les réglages relatifs au support d’impression «Carton» sont actifs. Recommandation : Utilisez ce réglage de l’air pour les supports d’impression dont le grammage est supérieur à 350 g/m².

Réglage de l’air pour papier

Les réglages relatifs au support d’impression «Papier» sont actifs.

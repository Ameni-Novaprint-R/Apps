Vue de la sélection d’encre

Lorsque vous sélectionnez un groupe d’impression dans la vue d’ensemble interactive de la presse, la base de données des couleurs s’ouvre pour permettre la sélection de l’encre pour le groupe d’impression respectif. Vous pouvez également accéder à la base de données des couleurs en sélectionnant l’affichage de l’encre dans la vue de la sélection d’encre.

La vue de la sélection d’encre fournit les informations suivantes sur les encres sélectionnées :

Vue

Fonction

Densité

Affichage de la densité de l’encre concernée

Filtre de couleur

Affichage du filtre de couleur de l’encre concernée

Valeurs de consigne L*a*b*

Affichage des valeurs de consigne L*a*b* de l’encre concernée

Le filtre de travail vous permet de rechercher une commande de façon ciblée à l’aide du numéro de la commande et du numéro de commande partielle.

Le bouton Rechercher vous permet de lancer la recherche.

Si la presse est munie de la configuration «LogoTronic», vous pouvez sélectionner «Local» ou «LogoTronic» comme filtre de travail.

Les données de commande vous fournissent des informations sur la commande que vous sélectionnez dans la vue d’ensemble.

Les fonctions de vue d’ensemble vous permettent de modifier l’affichage de la vue d’ensemble.

Le bouton Effacer la commande vous permet d’effacer la commande sélectionnée dans la vue d’ensemble.

Le bouton Appliquer vous permet de confirmer votre sélection et de retourner à l’écran du poste de commande Changement de travail.

Le bouton Annuler vous permet d’annuler votre sélection et de retourner à l’écran du poste de commande Changement de travail.

Accouplement/désaccouplement du margeur

Le bouton Accouplement du margeur permet d’engager manuellement le margeur.

Le bouton Désaccouplement du margeur permet de désengager manuellement le margeur.

Séquences de désaccouplement manuel :

●

Les feuilles restent sur la table à bandes aspirantes.

●

La marge est bloquée.

●

Toutes les feuilles qui se trouvent dans la presse sortent de cette dernière.

Le compteur de feuilles de travail attribue les feuilles comptées au travail actuel.

À l’aide des champs de saisie, vous pouvez modifier les données concernant les feuilles brutes et les bonnes feuilles. Le bouton Remise à zéro vous permet de les remettre à «0».

Le compteur total de feuilles compte toutes les feuilles entrant dans la presse. Vous ne pouvez pas modifier ce compteur.

Si vous activez le mode de configuration en cochant la case, le compteur de bonnes feuilles ne sera pas activé. Seules les feuilles de gâche sont comptées.

Vous avez en outre la possibilité de configurer des compteurs de feuilles définis par l’utilisateur. Ceux-ci ne sont pas limités dans le temps et restent mémorisés lors des changements de travail.

Donnée/Affichage

Fonction

Nom du compteurSaisir un nom pour le compteur dans le champ de saisie.
ActifCocher la case pour activer le compteur. Cela n’a aucune influence sur le compteur de feuilles de travail.
Remise à zéroEn actionnant ce bouton, remettre le compteur à «0».
BrutSaisir une valeur pour le nombre de feuilles brutes dans le champ de saisie.
Bonnes feuillesSaisir une valeur pour le nombre de bonnes feuilles dans le champ de saisie.
GâcheIndique la différence entre les feuilles brutes et les bonnes feuilles.
Valeur limiteDans le champ de saisie, saisir une valeur pour la détermination des feuilles sur la hauteur de pile.
Sens de comptageChanger de sens de comptage en actionnant ce bouton. Cette fonction est disponible uniquement lorsque la valeur limite n’est pas égale à «0».

Tab.: Affichages et réglages concernant les compteurs de feuilles définis par l’utilisateur

Le bouton Changement du sens de comptage du compteur de feuilles permet de définir le sens de comptage du compteur de feuilles défini par l’utilisateur.

Pour tous les compteurs de feuilles, vous avez la possibilité, à l’aide de menus déroulants, de sélectionner la réaction de la machine lorsque des valeurs présélectionnées sont atteintes aux compteurs.

Réaction

Description

Pas de réaction

Aucune réaction de la presse lorsque les réglages sont atteints.

Terminer le passage en pression

Le passage en pression se termine sans autre réaction.

Terminer le programme

Le programme actuel se termine.

Avertisseur sonore

La presse klaxonne et continue à imprimer jusqu’à ce que l’opérateur arrête le programme.

Arrêter la presse

La presse klaxonne et s’arrête.

Tirage corrigé - Print Clean

La presse imprime un nombre défini de feuilles d’impression avec groupe d’encrage hors contact.

Avertisseur sonore et tirage corrigé

La presse klaxonne et lance le tirage corrigé.

Tab.: Réactions de la presse

Si vous sélectionnez la réaction «Tirage corrigé», vous pouvez alors saisir un nombre de feuilles pour la fonction Tirage corrigé - Print Clean dans le champ de saisie correspondant. Lorsque le volume de tirage ou le nombre de feuilles de configuration est atteint, le groupe d’encrage est mis hors contact et le nombre de feuilles réglé est imprimé. Ainsi, avant le changement de travail, l’encre et l’agent de mouillage sont réduits sur les plaques d’impression et sur les blanchets. L’ampleur du nettoyage pour plaques d’impression et blanchets est limitée à un minimum.

En cochant la case, vous sélectionnez la fonction Réduction de l’encre - CleanTronic FastInkUp. Le nombre de feuilles de gâche diminue après le démarrage du travail suivant.

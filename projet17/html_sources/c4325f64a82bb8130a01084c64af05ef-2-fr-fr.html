Vue «Menu d’état du réglage du format»

La vue Menu d’état du réglage du format vous permet de surveiller les réglages du format du passage des feuilles.

Pour ouvrir la vue, actionnez l’affichage d’état dans l’écran du poste de commande Passage des feuilles.

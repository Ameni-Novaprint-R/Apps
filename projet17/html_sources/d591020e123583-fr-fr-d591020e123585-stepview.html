Endommagement de composants dû à des contraintes mécaniques ! Risque de rupture. Ne pas contraindre mécaniquement le composant.

1.

Placez avec précaution le module de rechange UV dans le puits.

2.

Verrouillez le module de rechange UV en actionnant le commutateur de déverrouillage.

3.

Retirez les tuyaux d’eau et la fiche électrique des adaptateurs de position de repos.

4.

Branchez les tuyaux d’eau sur les raccordements d’eau du module de rechange UV.

5.

Branchez la fiche électrique sur le raccordement et verrouillez celui-ci.

6.

Abaissez le couvercle du puits et laissez-le s’enclencher.

7.

Fermez le couvercle du côté commande du groupe d’impression.

Le remplacement du module de rechange UV par un module de rechange IR s’effectue dans l’ordre inverse.

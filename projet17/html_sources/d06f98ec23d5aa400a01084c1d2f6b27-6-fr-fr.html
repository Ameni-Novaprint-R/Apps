L’écran du poste de commande Stations d’aspiration vous permet de régler les stations d’aspiration sur le format du support d’impression.

Il est possible d’effectuer un réglage de précision des stations d’aspiration via l’écran tactile de la sortie.

Dans la représentation graphique des stations d’aspiration, vous pouvez voir le positionnement sélectionné des stations d’aspiration.

Sélectionnez la position de repos hors du format maximal du support d’impression pour les stations d’aspiration en cochant les cases correspondantes.

Dans les champs de saisie, saisissez la position souhaitée des stations d’aspiration.

L’affichage d’état (voir Chap. «Affichage de l’état») vous renseigne sur le statut du positionnement des stations d’aspiration.

À l’aide du bouton Activer le réglage, vous confirmez vos réglages et appliquez ces derniers à la presse.

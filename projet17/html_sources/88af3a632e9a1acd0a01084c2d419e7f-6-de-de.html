Bedruckstoff neu anlegen

  • Start
  • Leitstand
  • Betrieb
  • Maschine einrichten und einstellen
  • Hauptmaske „Auftrag“
  • Bedruckstoff einrichten
  • Bedruckstoff neu anlegen
×

Nach dem Laden eines Auftrags erfolgen die Einstellungen in der Leitstandsmaske Bedruckstoff.

Voraussetzungen:

✓

Die Maschine ist eingeschaltet.

✓

Die Maschine steht still.

✓

Der Auftrag ist geladen.

✓

Die Leitstandsmaske Bedruckstoff ist geöffnet (siehe Kap. „Untermaske „Bedruckstoff““).

Einzelschritte

1.

Betätigen Sie die Schaltfläche Neuer Bedruckstoff

▷

Das Popup-Fenster Neuer Bedruckstoff wird geöffnet (siehe Kap. „Popup-Fenster „Neuer Bedruckstoff““).

2.

Geben Sie die Werte für den neuen Bedruckstoff ein.

3.

Betätigen Sie die Schaltfläche Anwenden.

▷

Die Werte für den Bedruckstoff werden gespeichert.

▷

Dem Bedruckstoff werden die aktuell in der Maschine eingestellten Werte für die Bogenführung zugeordnet.

▷

Das Fenster wird geschlossen.

▷

Der Bedruckstoff wird in die Liste übernommen.

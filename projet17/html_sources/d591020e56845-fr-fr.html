Contrôle de double feuille à ultrasons

Le contrôle de double feuille à ultrasons est intégré dans une traverse au milieu de la table de marge. Il vérifie si des doubles feuilles entrent dans la marge. Le contrôle de double feuille à ultrasons fonctionne après la mise en marche de la presse. Le système opère automatiquement.

Si le contrôle de double feuille à ultrasons détecte une double feuille, la commande bloque la marge.

Le contrôle de double feuille à ultrasons ne peut pas être désactivé.

Selon le support d’impression, il est possible de choisir entre 3 modes de fonctionnement sur l’écran tactile de la marge. Il est également possible de configurer le contrôle de double feuille sur l’écran du poste de commande Passage des feuilles (voir Chap. «Sous-écran «Passage des feuilles»»).

Les modes de fonctionnement suivants sont disponibles :

Contrôle de double feuille automatiqueSi cette fonction est activée, le mode de fonctionnement le mieux adapté à la détection des doubles feuilles est automatiquement sélectionné. Le système automatisé fonctionne avec toutes les variantes d’équipement. En mode automatique, le niveau actif est affiché. Si le système automatisé est désactivé, le niveau peut être sélectionné selon le support d’impression. Dans le cas de grammages < 150 g, il convient de toujours utiliser la fonction «Système automatisé désactivé/Sélection « niveau bas »».
 Contrôle de double feuille «Niveau sonore super silencieux» (option)L’appareil fonctionne avec un niveau sonore super silencieux pour les supports d’impression extrêmement fins, p. ex. les notices explicatives.
Contrôle de double feuille «Niveau sonore silencieux»L’appareil fonctionne avec un niveau sonore bas pour supports d’impression fins ou carton recyclé, par exemple pour papier mince, films plastique à partir de 0,4 mm d’épaisseur, films autocollants et cartons à cannelures extra-fines
Contrôle de double feuille «Niveau sonore élevé»L’appareil fonctionne avec un niveau sonore élevé pour supports d’impression épais, par exemple pour carton légèrement hétérogène, feuilles d’impression doublées de métal et cartons à cannelures extra-fines.

Le contrôle de double feuille à ultrasons détecte tous les supports d’impression usuels. Le traitement de certains supports d’impression spéciaux peut cependant déclencher le contrôle de double feuille à ultrasons bien qu’il ne s’agisse pas d’une double feuille.

3.

Bei vorhandener Option ErgoTronic ICR kann die Registermessung hier eingeschaltet oder ausgeschaltet werden: Betätigen Sie die Schaltfläche Messung Register.

▷

Bei eingeschalteter Registermessung werden die Registermarken im Messstreifen während einer Messfahrt mit ausgemessen.

4.

Die L*a*b*-Messung kann hier eingeschaltet oder ausgeschaltet werden: Betätigen Sie die Schaltfläche LAB-Messung.

5.

Slopekalibrierung einschalten oder ausschalten: Betätigen Sie die Schaltfläche Slopekalibrierung.

▷

Mit der Slopekalibrierung werden verschiedene Messgeräte auf eine gemeinsame Referenz bezogen. Dies bezieht sich auf die Dichtemessung. Wenn die Slopekalibrierung aktiv ist, erhält die Menüzeile mit den Bedienelementen einen orangefarbenen Hintergrund. Auf diese Weise ist sichtbar, dass die Funktion eingeschaltet ist.

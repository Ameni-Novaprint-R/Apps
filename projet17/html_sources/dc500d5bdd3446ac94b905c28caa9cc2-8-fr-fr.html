L’entraînement déplace le support de rouleau depuis le poste de commande pour le placer sur le format sélectionné. Le support de rouleau est un support situé au-dessus de la table à bandes aspirantes sur lequel sont placés les rouleaux de transport et les galets-brosses.

Le dispositif de verrouillage permet d’ouvrir le support de rouleau.

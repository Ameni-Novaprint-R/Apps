ErgoTronic Color Quality Protocol

Nach Beendigung eines Druckdurchgangs erzeugt das System automatisch ein Protokoll, das einen Überblick über die mit ErgoTronic ColorControl/ColorDrive gemessenen Farbwerte im L*a*b*/LCh-Farbraum gibt.

Die Option ErgoTronic LAB muss vorhanden und aktiv sein.

Das ErgoTronic Color Quality Protocol wird als PDF-Datei ausgegeben, sein Name setzt sich wie folgt zusammen:

Auftragsnummer-Teilauftragsnummer-Druckdurchgangsnummer.pdf

Wo das Protokoll abrufbar ist, wird bei der Inbetriebnahme des Systems individuell festgelegt.

Für jede Druckfarbe erfolgt die Auswertung separat. Zu jeder Farbe existieren 3 verschiedene Ansichten:

●

Tabellenansicht (siehe Kap. „Tabellenansicht“)

●

Statistikansicht (siehe Kap. „ErgoTronic Color Quality Protocol“)

●

Grafische Ansicht (siehe Kap. „ErgoTronic Color Quality Protocol“)

Die verschiedenen Ansichten werden neben weiteren Bestandteilen des Protokolls im Folgenden näher beschrieben.

  • Auftragsdaten
  • Tabellenansicht
  • Statistikansicht
  • Grafische Ansicht
  • Messbedingungen

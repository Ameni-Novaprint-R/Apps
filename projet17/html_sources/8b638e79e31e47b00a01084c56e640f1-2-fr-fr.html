Mode manuel

Dans le menu de l’écran tactile Mode manuel, vous pouvez régler et commander manuellement la table de marge, la table à bandes aspirantes et le margeur.

Vous pouvez appeler le menu de l’écran tactile au moyen du bouton Mode manuel.

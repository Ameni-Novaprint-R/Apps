1.

Ziehen Sie den Verriegelungsknopf auf der Bedienseite am Waschbalken nach außen.

2.

Schwenken Sie die Schmutztuchspindel auf der Bedienseite heraus.

3.

Ziehen Sie die Schmutztuchspindel aus der Aufnahme an der Antriebsseite heraus.

4.

Ziehen Sie den Verriegelungsknopf auf der Antriebsseite am Waschbalken nach außen.

5.

6.

Ziehen Sie die Saubertuchspindel aus der Aufnahme an der Bedienseite heraus.

7.

Wickeln Sie das gebrauchte Waschtuch von den Spindeln ab.

8.

Entsorgen Sie das gebrauchte Waschtuch bestimmungsgerecht.

La vue d’ensemble interactive de la presse (1) permet de voir les groupes d’encrage de quelles tours d’impression vous pouvez sélectionner.

Sélectionnez les groupes d’encrage (2) en cochant les cases correspondantes. Seuls les groupes d’encrage connectés peuvent être sélectionnés.

Activez le processus de maintenance (3) du groupe d’impression en cochant les cases correspondantes. L’affichage d’état (voir Chap. «Affichage de l’état») renseigne sur l’état actuel du processus de maintenance.

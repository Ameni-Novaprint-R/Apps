Slopekalibrierung einrichten

Das Messgerät wird bei einer Slopekalibrierung neu skaliert, damit mit unterschiedlichen Messgeräten gleiche Messergebnisse erhalten werden. So kann die Anzeige an andere vorhandene Messgeräte angepasst werden.

Die Slopekalibrierung eignet sich nur zur Farbdichtemessung. Die Farbdichtewerte müssen im üblichen Arbeitsbereich liegen.

Wir empfehlen ErgoTronic ColorDrive als Referenzmessgerät zu definieren und ggf. andere Densitometer an die ErgoTronic anzupassen. Prüfen Sie immer, ob an beiden Messgeräten die gleichen Messbedingungen eingestellt sind.

Slopekalibrierung durchführen:

1.

Legen Sie eine Referenzkarte oder Prüfkarte mit Farbdichte-Messwerten eines externen Messgerätes auf den Messtisch an den vorderen Bogenanschlag.

2.

Rufen Sie die Maske Messen auf.

3.

Rufen Sie die Maske Einstellungen auf.

Betätigen Sie die Schaltfläche Slopekalibrierung.

6.

Nehmen Sie den Messkopf von der Schiene.

7.

Legen Sie den Messkopf an eine unbedruckte Stelle auf die Referenzkarte.

8.

Betätigen Sie die Schaltfläche Papierweißmessung.

▷

Die Papierweißmessung wird durchgeführt.

▷

Die Schaltflächen mit dem Pipettensymbol werden anklickbar.

9.

Legen Sie den Messkopf an der gewünschten Position auf die Referenzkarte.

10.

Farbwert messen: Betätigen Sie die Schaltfläche Farbwert messen.

▷

Der gemessene Farbwert erscheint rechts neben dem Buchstaben für die entsprechende Farbe.

11.

Farbwert übernehmen: Geben Sie den auf der Referenzkarte angegebenen Wert in das Eingabefeld rechts neben dem gemessenen Wert ein. Verwenden Sie dazu den Bildschirm-Taschenrechner.

12.

Einen neuen Farbwert messen und übernehmen: Wiederholen Sie die Schritte und geben Sie die neuen Farbwerte für alle Farben ein.

13.

Bei Bedarf betätigen Sie jederzeit die Schaltfläche Abbruch.

14.

Wenn Sie die Farbwerte für alle Farben eingegeben haben:

Betätigen Sie die Schaltfläche Anwenden.

▷

Die neu eingerichtete Slopekalibrierung wird automatisch aktiviert und die Menüzeile erhält einen orangefarbenen Hintergrund.

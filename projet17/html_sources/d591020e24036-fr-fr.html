Affichages de solution de mouillage

Dans la vue Affichages de solution de mouillage, vous pouvez régler la concentration ou la température de la solution de mouillage.

Dans l’écran du poste de commande Solution de mouillage, vous pouvez sélectionner les affichages de solution de mouillage suivants :

Affichage de produit de mouillage

Fonction

TempératureAfficher et régler la température de la solution de mouillage
IsopropanolAfficher et régler l’isopropanol de la solution de mouillage
Valeur guideAfficher et régler la valeur guide de la solution de mouillage
Valeur pHAfficher et régler le pH de la solution de mouillage

Tab.: Affichages de solution de mouillage dans l’écran du poste de commande Solution de mouillage

Tous les affichages de solution de mouillage ont la même structure.

  • Accueil
  • Poste de commande
  • Description de la machine
  • Écrans du poste de commande
  • Écran principal «Groupe d’encrage et groupe de mouillage»
  • Sous-écran «Solution de mouillage»
  • Affichages de solution de mouillage

Les affichages de solution de mouillage proposent les fonctions supplémentaires suivantes :

Bouton

Fonction

 Valeur d’alarme supérieure

Dans le champ de saisie, saisir la valeur limite supérieure pour la solution de mouillage.

 Valeur de consigne

Dans le champ de saisie, saisir la valeur de consigne pour la solution de mouillage.

 Valeur d’alarme inférieure

Dans le champ de saisie, saisir la valeur limite inférieure pour la solution de mouillage.

Fermer

Fermer l’affichage de solution de mouillage.

Enter

Confirmer la saisie et fermer la vue.

Section finale pour la feuille

Le menu de l’écran tactile Section finale pour la feuille vous permet de régler les bandes d’aspiration, les roues de serrage et les souffleurs de coin.

Vous pouvez appeler le menu de l’écran tactile au moyen du bouton Section finale pour la feuille.

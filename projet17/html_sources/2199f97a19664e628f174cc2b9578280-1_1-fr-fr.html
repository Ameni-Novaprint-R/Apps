Sélectionner/désélectionner tous les champs de saisie

Le bouton Sélection/désélection de tous les champs de saisie permet de sélectionner tous les éléments disponibles.

Vous pouvez régler les valeurs soit individuellement soit globalement.

Bouton

Description

Lorsque le bouton Un seul champ de saisie sélectionné s’affiche, vous ne pouvez sélectionner qu’un seul champ de saisie et régler sa valeur.

Lorsque le bouton Tous les champs de saisie sélectionnés s’affiche, tous les champs de saisie du menu de l’écran tactile sont sélectionnés.

Vous pouvez augmenter ou diminuer toutes les saisies de la même valeur.

Tab.: Sélectionner/désélectionner tous les champs de saisie
